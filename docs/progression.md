# 第2段階: スターター・転生・研究

2026-10-30。v2.058の固定ミラーを引き続き参照する。全機能完成ではなく、前段階に実際に遊べる進行系を追加したもの。

## スターター

新規工房に1,000枚を支給。独自のユーザー指定ルールであり、原作仕様ではない。これは残高にだけ加算し、焼いた枚数や転生の累計には加算しない。売却時の累計補正でも贈与分を差し引く。転生後には再支給しない。既存v1/v2/v3の残高を上書きしたり、ロードのたびに追加したりしない。

## 実装した進行

- 通常強化は合計517件。基本300に加え、固定効果と解禁条件が確認できたレシピ114、Milk型15、Mouse型15、炉守りシナジー18、通常シナジー36、転生倍率有効化5、研究棟と研究9件、GC強化3、休戦延長1。
- 実績は合計410条件。保有298に、焼成/生産速度の閾値95、クリック生産15、炉守り連携2を追加。Milkの数値はこれらの獲得数に依存し、Kitten型は個別乗算。
- 通常モードの転生。累計の立方根から今回の差分だけチップを支給。二重転生防止、通常施設/強化/研究/イベントのリセット、実績と天界取得の保持。GC通算クリック数も保持。
- 天界は129節点の価格/前提データを構築（直接定義94、施設解放20、tier解放15）。独自IDと独自表示名を使用。80節点の効果を実装し、未対応49は購入対象にしない。実装済みでも未対応の親節点がある場合は到達できない。特別な解禁条件を持つ未監査節点は解放しない。
- 天界チップの価格はceil。永続スロット5枠は購入済み対象だけを選択でき、重複配置や研究・倍率有効化の保持は禁止。
- 施設/強化割引、レシピ箱、Milk系天界効果、初期施設、通常シナジーの書、Unshackled数値効果、研究短縮。
- 研究棟は炉守り6台と炉守りシナジー7種類で得る永続実績で解禁。次周回ではこの実績を保持するので、炉守り6台で再解禁する。次の研究は購入後30分（記録継承で3分）。研究9件、異変3段階、段階別の炉守り基礎値加算、休戦、価格の8倍増とcap、永久休戦のCpS×.95、解除。
- 通常吸収体と希少吸収体。段階別出現確率、10秒接近、1体5%の吸収、各個体への全吸収量の蓄積、110%返却、希少×3、天界の枠+2/出現×5/返却×1.05。
- 30fpsのイベント時計、自然な光/闇イベント、条件付き候補と前回結果除去、Lucky/Ruin、主要バフ、施設保有数スナップショット、同じ施設の時間延長、異なる施設の重複、連鎖、雨粒回収。砂糖・竜・季節に依存する抽選分岐と演出用乱数は未対応。**完全なGC抽選互換は未達**。
- オフライン天界: 最適1時間・5%が起点、7段階の割合+10ポイント/最適時間×2、複合節点の+5ポイント/+2日、超過分は効率×.1。バフを除外し、保存された残り時間は復帰後に再開。庭のドロップやFortuneによる補正は未対応。
- v3セーブ: 通常/天界取得、転生、スロット、研究、休戦、吸収量、通算イベント、バフの保存と検証。ロード時は画面の光/雨粒を消し、同じ報酬の二重回収を防ぐ。旧版に保存されていない手動生産の累計は推測せず0から記録する。

## 追加の出典と照合

`tools/extract-progression.mjs` はハッシュ固定の参照ソースを構文解析する。動的効果、季節/ドロップ制御など未解決132件はnullを伴う調査レコードに残し、架空の効果で解禁しない。

`tools/reference-progression.mjs` で参照側CalculateGains、GetTieredCpsMult、GetHeavenlyMultiplier、各施設cps、mouseCpsを隔離VMで実行し、24組合せの数値出力を保存。レシピ、Kitten、Mouse、シナジー、研究、転生、Unshackled、永久休戦がある場合のraw/unbuffed/CpS/CpCを比較した。ミニゲーム、オーラ、外部Herald値は無効化した比較。公式実機一致を意味しない。

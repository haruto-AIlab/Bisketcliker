## 今回完成させる単位

第1段階は20施設、基本300強化、保有実績298、価格/部分購入/売却、基礎CpS/CpC、4種バフのエンジン、独自セーブ形式とそのUI。通常強化285は各施設×2、手しごと15は初期3件の倍化と後続加算系列。保有実績は所有数が下がっても残る。バフの自然出現はまだない。
